# New.Vision — Phase-Wise Build Prompt

**Concept:** *New.Vision — the free vision board & life-design studio.*
Free interactive tools (vision board maker, SMART/WOOP goal planner, Wheel of Life, affirmation generator, letter-to-future-self), backed by in-depth guides and curated videos. Monetized with Google AdSense, a coaching/strategy-session lead funnel, sponsorships, donations and an annual vision board contest.

## Why this idea wins for New.Vision

| Factor | Evidence / logic |
|---|---|
| Exact-match intent | "new vision" = new year, new goals, new life plan. The domain reads as the product. |
| Search demand | "vision board", "vision board ideas", "how to make a vision board", "goal setting", "new year's resolutions" are evergreen, multi-million monthly global queries with a hard seasonal spike Nov–Jan (launching mid-November = launching into peak). |
| Repeat visits | Tools save to the browser and get revisited daily (daily prompt, affirmation of the day, goal check-ins) → more pageviews per user → more ad impressions. |
| RPM lift | Career, money and business-goal guides pull higher-CPC advertisers (coaching, courses, finance apps, planners) than generic motivation content. |
| Lead value | Coaching / strategy-session leads sell or refer at $25–$200 each; team workshop leads are worth more. Wheel of Life → coach funnels are a proven model (noomii, coach.me, Psychology Today). |
| Trademark safety | Avoids every "New Vision" mark cluster found: eye care / LASIK, supplements (Class 5), Ugandan newspaper, cosmetics. Brand is always written **New.Vision** with the dot, and a disclosure page states non-affiliation. |
| Hosting | 100% static HTML/CSS/JS → free GitHub Pages (main branch, root). Automation via a free scheduled GitHub Action. |

### Rejected alternatives
- **Eye care / vision correction** — crowded with "New Vision" registered marks, YMYL medical review burden for AdSense, high legal risk.
- **Tech/innovation news ("new vision of the future")** — needs daily editorial output to rank; thin-content risk for AdSense.
- **AI image "vision" generator** — needs paid APIs and a backend; not free-hostable.

## Phase 0 — Foundations
1. Static site, no framework, no build step required to serve. `index.html` at repo root, `.nojekyll`, relative links so it works at `username.github.io/New-vision/` and at `new.vision`.
2. Shared header/footer generated by `tools/build.py` (Python 3, no dependencies). Re-run after editing content.
3. Every page `<head>`: meta description, canonical (`https://new.vision/...`), Open Graph/Twitter cards, JSON-LD, favicon SVG, manifest, and the AdSense loader exactly:
   `<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-6620975821265271" crossorigin="anonymous"></script>`
4. `ads.txt` → `google.com, pub-6620975821265271, DIRECT, f08c47fec0942fa0`.
5. Top banner on every page: "Contact, if you are interested in this website / domain name / Sponsorship / Advertisement / Partnership" → `https://web.works/contact`. The URL never appears as visible text.

## Phase 1 — Design system
- Brand: **New.Vision**, dot rendered as a glowing gradient "lens".
- Palette: night `#0c0b1d`, ink `#1b1a33`, violet `#7c5cff`, cyan `#22d3ee`, peach `#ffb86b`, paper `#fbfaff`. Aurora gradient for heroes/CTAs.
- Type: Fraunces (display) + Inter (UI/body), system fallbacks.
- Components: glass cards, pill buttons, tool tiles, stat counters, progress bars, accordion FAQ, toast, modal, tabs, responsive nav with mobile drawer, dark-mode toggle, reduced-motion support, focus-visible states, skip link.

## Phase 2 — Interactive tools (the traffic engine)
1. **Vision Board Maker** — 6/9/12 tile layouts, image upload (client-side resize), gradient + text tiles, emoji/icon stickers, 6 starter templates, drag to swap tiles, autosave to localStorage, export high-res PNG, print, share.
2. **Goal Planner** — 5-step SMART wizard + WOOP (Wish, Outcome, Obstacle, Plan), quarterly milestones auto-generated, saved goal list with progress sliders, download `.ics` calendar reminders and `.txt`.
3. **Wheel of Life** — 8 life areas, 1–10 sliders, live radar chart, balance score, lowest-area action tips, PNG export → CTA to coaching.
4. **Affirmation Generator** — 8 categories, personalised by name, "affirmation of the day" (date-seeded), copy/share, favourites.
5. **Letter to Future Self** — write, pick delivery date, download `.ics` reminder containing the letter + `.txt` copy (private, no server).
6. **New Year Countdown** + **Daily Vision Prompt** on home.

## Phase 3 — Content (AdSense approval + SEO)
- 10+ original long-form guides (700–1,200 words) with key takeaways, TOC, FAQ, internal links, references, last-updated date: how to make a vision board; does it work (mental contrasting, implementation intentions); SMART vs OKR vs WOOP; 2027 vision board ideas; Wheel of Life; resolutions that stick; career vision plan; money vision board; personal vision statement examples; affirmations that work.
- Video library with click-to-load YouTube embeds (privacy-enhanced `youtube-nocookie.com`), credited to creators.
- Required pages: About, Contact, Privacy (AdSense/DoubleClick cookies, opt-out links), Terms, Disclaimer + Trademark/Copyright disclosure, 404, sitemap.xml, robots.txt.
- No thin pages, no "coming soon" pages, no prohibited content, ads never placed next to buttons or inside tools.

## Phase 4 — Lead generation (highest-value section)
- `/coaching.html` "Vision Strategy Session": 3-step form (focus area → timeline & budget → contact), trust bullets, FAQ, sticky CTA. Separate tracks for **individuals**, **teams/companies (workshops)** and **coaches who want to be listed**.
- Free **2027 Vision Workbook** lead magnet (email → instant access to printable workbook page).
- Inline lead CTAs after every tool result and in every guide.

## Phase 5 — Support, sponsorship, hiring, contests
- `/support.html`: preset support amounts ($5/$25/$100/custom) as pledges, monthly supporter tiers, sponsorship tiers, "what your support funds" progress bars (operations, promotion & marketing, hiring talent, contest prizes).
- `/careers.html`: open roles + application form.
- `/contest.html`: "Vision Board of the Year 2027" — prizes, timeline, judging criteria, official rules (no purchase necessary, eligibility, void where prohibited), entry form.

## Phase 6 — Forms & privacy of the contact address
- All forms POST via `fetch` to FormSubmit's AJAX endpoint. The destination address is assembled at runtime from character codes; it never appears in HTML, text or as a `mailto:`.
- Honeypot field, `_subject` per form, `_template: table`, success/error toasts.
- First submission triggers a one-time FormSubmit activation email — click it once.

## Phase 7 — Automation / self-updating
- `automation/daily-refresh.yml` (activate by moving into `.github/workflows/`) runs daily (cron) and on demand: `tools/refresh.py` rotates the daily prompt, affirmation, featured guide & video into `data/daily.json`, refreshes `sitemap.xml` lastmod, commits back to `main`. Pages redeploys automatically.
- Client-side fallbacks (date-seeded) so the site still updates daily if the Action is paused.
